# Home Connect Pro

That's Pangisa. Build it. With it one can find a house or home to rent. But for this tenant or mupangisa they can't get landlord contact and exact location of rental though area is showed on map, getting directions to actual place and getting in touch with property owner or landlord requires access which is paid for one time revealing both hence connecting them that way, after transaction property owner gets that persons phone number and tenant too gets landlords which they can call. Now when this platform access fee is charged the property is then removed from visibility to others, landlord can switch it back to live if the two can't continue, if not landlord, tenant too can let it go if they won't go further with it, landlords are the main here if they switch they switch it goes back to being visible. Note that landlords too are charged to make listing live so they can add all property details but going live requires fee payment. This fee is 5% of the listed tenant renting price. Tenants too are charged a percentage dependent on the house rent they go for. This platform connects to Google maps plus makes it easy to drop property location for property owners. Then comes those who refer others, those ones get a unique code like ID could be PanXXXX, this is provided on somewhere maybe account creation and is optional, but it is also attached to the link they get that they can share and if identified lists that tenant or property owner under them, of course the first counts if multiple refer same person or role. Now these get 3% of what we charge, plus it's one account for all these one can just switch role easily. They get a simple minimal dashboard to track earnings predicted and can request withdraw if 5000 UGX is reached which appears to admin. The properties come with optional video embed like from YouTube showing property tour. Now there could be properties with units, if units it means we charge for each unit if property owner is to list, plus it shows how many units are left, but comes with a little discount if units. Tenants who go through with access payment can leave optional silent reviews about landlords and property these are visible to admin not anywhere else. Properties can be shared if shared by affiliate that link goes with affiliate ID for tracking and ofcourse commissioning. Landlords are optionally required to submit national ID for verification purposes plus this appears as label verified. Verified ones appear first. Now property details to fill are many. Be sure to request ones applicable to Uganda.
